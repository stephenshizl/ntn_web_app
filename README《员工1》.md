# NTN终端PC配置台

版本：V0.1.0  
日期：2026-10-16  
需求依据：软件需求书V3.0的V3-55、V3-56  

## 当前功能

- Chrome／Edge桌面版Web Serial串口选择、授权、连接、断开和拔插提示；
- 9600、19200、38400、57600、115200波特率，固定8N1、无流控；
- 持续异步读取，同时显示文本转义视图和原始HEX；
- 版本、能力、状态、配置、队列、GNSS、时间、接收模式快捷查询；
- 工作模式、域名/IP、端口、APN、接收模式、DNS、SN、资产上报和RAW分块配置；
- 模式1一键执行`+++`静默保护及`AT+MCUCFG=1`维护入口；
- `AT+MCURS232`改速，在收到`MCUPENDING`后自动按新波特率重开并查询；
- 任意文本、AT和二进制HEX发送；
- 原始串口记录导出为NDJSON。

## 启动

双击：

```text
start.bat
```

或者在PowerShell运行：

```powershell
.\start.ps1
```

默认打开`http://127.0.0.1:18787/`。Web Serial需要localhost或HTTPS，不能直接双击`index.html`使用。

## 开发与测试

页面无第三方运行依赖。协议工具测试需要Node.js：

```powershell
npm test
```

也可直接执行：

```powershell
node --test
```

## 演示顺序

1. 使用USB转RS232连接终端，打开页面并选择设备实际波特率。出厂默认19200，页面首次打开也默认19200；已保存的网页偏好和设备NV速率需分别核对。
2. 首次点击“选择并连接串口”，在浏览器授权窗口选择对应COM口。已有且仅有一个授权端口时，可点击“连接已授权串口”直接重连；未授权或有多个端口时仍须明确选择目标。
3. 模式0可直接执行版本、状态、GNSS和时间查询。
4. 模式1先点击“执行 +++ 维护宏”，显示维护成功后再执行配置命令。
5. 改速时等待网页自动重开，随后核对`AT+MCURS232?`返回的保存值和生效值。
6. 退出维护后，文本或HEX区可用于模式1 RAW上行演示。
7. 演示结束导出NDJSON日志，与MCU RTT和服务器收包记录对照。

## 已知边界

- 必须使用支持Web Serial的桌面Chromium浏览器；Firefox和Safari不支持。
- 串口选择必须由用户点击并授权，网页不能绕过浏览器权限自动打开任意COM口。“连接已授权串口”只复用当前站点已有授权。
- 中英文切换在当前页面内更新文字，保留串口连接、表单和日志。固件重启、断开或返回模式0后，旧维护标记会失效。
- 浏览器定时器不是硬实时；连续传感器流无法形成`+++`静默窗口时使用Android蓝牙配置。
- P0不实现固件差分／全量升级、RS232业务下行开关和生产级权限审计。
- 表单内容只代表网页输入，必须看到终端返回`OK`并重新查询确认后才算设备保存成功。
